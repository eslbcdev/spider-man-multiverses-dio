# Spider-Man Multiversos

🇧🇷 Versão em Português

## Carrossel Temático: Multiverso do Homem-Aranha
Um projeto de front-end que apresenta um carrossel de imagens interativo e animado, homenageando as três versões cinematográficas do Homem-Aranha interpretadas por Tobey Maguire, Tom Holland e Andrew Garfield. O projeto foi desenvolvido para aprimorar e demonstrar habilidades avançadas em CSS e JavaScript.

## 🎬 Demonstração

https://github.com/user-attachments/assets/3e74e9b7-74cd-456d-a56d-7274767d71d5

## ✨ Sobre o Projeto
O objetivo foi criar um componente de UI (Interface de Usuário) moderno e visualmente cativante do zero. O carrossel não apenas alterna entre os personagens, mas também atualiza dinamicamente o plano de fundo e os estados dos elementos de navegação, criando uma experiência coesa e imersiva para o usuário.

## 🚀 Funcionalidades
* **Carrossel 3D Animado:** As imagens laterais são rotacionadas e diminuídas, criando uma sensação de profundidade. As transições entre os slides são suaves e fluidas.

* **Navegação Múltipla:** O usuário pode navegar pelo carrossel de três formas:

  * Clicando no menu superior (com os nomes dos atores).

  * Clicando na paginação numerada na parte inferior.

  * Clicando diretamente nas imagens laterais.

  * Fundo Dinâmico: O plano de fundo da página muda suavemente para corresponder ao personagem que está em destaque no carrossel.

  * Design Temático: Toda a interface, incluindo cores, fontes e imagens, foi escolhida para se alinhar ao universo do Homem-Aranha.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Para a estrutura semântica do carrossel e da navegação.

* **CSS3:** Para toda a parte visual, incluindo:

  * Flexbox para o alinhamento dos elementos.

  * CSS Transforms (rotate, scale, translate) para criar o efeito 3D e posicionar os cards.

  * CSS Transitions para garantir as animações suaves de movimento, rotação e troca de plano de fundo.

  * Pseudo-classes (:hover) para a interatividade dos botões.

* **JavaScript:** Para orquestrar toda a interatividade:

  * Manipulação de Eventos (click) para capturar as ações do usuário.

  * Manipulação de Classes do DOM para alterar o estado do carrossel (adicionar/remover classes como .active) e acionar as transições CSS.

## 📚 Objetivos de Aprendizagem
Construir um componente de carrossel complexo e funcional sem o uso de bibliotecas externas.

Aplicar transformações e transições avançadas de CSS para criar animações sofisticadas.

Gerenciar o estado de uma interface com JavaScript, sincronizando múltiplos elementos (cards, fundo, navegação) com base na interação do usuário.

Praticar a estruturação de um código limpo e organizado para um componente interativo.

## Themed Carousel: Spider-Man Multiverse
A front-end project featuring an interactive and animated image carousel, paying tribute to the three cinematic versions of Spider-Man portrayed by Tobey Maguire, Tom Holland, and Andrew Garfield. This project was developed to enhance and demonstrate advanced skills in CSS and JavaScript.

## 🎬 Demonstration

https://github.com/user-attachments/assets/3e74e9b7-74cd-456d-a56d-7274767d71d5

## ✨ About the Project
The goal was to create a modern and visually captivating UI (User Interface) component from scratch. The carousel not only cycles through the characters but also dynamically updates the background and the state of navigation elements, creating a cohesive and immersive user experience.

## 🚀 Features
* **Animated 3D Carousel:** The side images are rotated and scaled down, creating a sense of depth. Transitions between slides are smooth and fluid.

* **Multiple Navigation Methods:** The user can navigate the carousel in three ways:

  * By clicking the top menu (with the actors' names).

  * By clicking the numbered pagination at the bottom.

  * By clicking directly on the side images.

  * Dynamic Background: The page's background smoothly changes to match the character currently featured in the carousel.

  * Themed Design: The entire interface, including colors, fonts, and imagery, was chosen to align with the Spider-Man universe.

## 🛠️ Technologies Used
* **HTML5:** For the semantic structure of the carousel and navigation.

* **CSS3:** For the entire visual presentation, including:

  * Flexbox for element alignment.

  * CSS Transforms (rotate, scale, translate) to create the 3D effect and position the cards.

  * CSS Transitions to ensure smooth animations for movement, rotation, and background changes.

  * Pseudo-classes (:hover) for button interactivity.

* **JavaScript:** To orchestrate all interactivity:

  * Event Handling (click) to capture user actions.

  * DOM Class Manipulation to change the carousel's state (adding/removing classes like .active) and trigger the CSS transitions.

## 📚 Learning Objectives
To build a complex and functional carousel component without using external libraries.

To apply advanced CSS transforms and transitions to create sophisticated animations.

To manage the state of an interface with JavaScript, synchronizing multiple elements (cards, background, navigation) based on user interaction.

To practice structuring clean and organized code for an interactive component.
